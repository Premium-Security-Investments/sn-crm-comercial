# AGT-002 R1 — gate de entrada y punto de alto

**Fecha:** 2026-10-03
**Estado:** `R1_GATE_REACHED_NOT_OPEN_FOR_IMPLEMENTATION`
**Límite:** evaluación documental y técnica; sin código R1, migración, despliegue, proveedor ni producción

## 1. Qué significa haber llegado a R1

El orden autorizado llegó al gate que sigue a `INITIAL`. Esto no equivale a iniciar ni completar
R1. La implementación de reanálisis incremental continúa cerrada hasta satisfacer sus
precondiciones y obtener un gate separado.

R1 conserva este alcance: ante un evento confiable sobre una oportunidad convertida que ya tiene
una corrida canónica válida, calcular sólo el delta y crear una versión canónica sucesora
append-only. R1 nunca crea la primera corrida, nunca reemplaza `INITIAL`, nunca decide GO/NO-GO y
nunca ejecuta acciones externas.

## 4. Resultado del gate

Se alcanza formalmente R1 como siguiente frente, pero no se abre su implementación. El estado
correcto es `gate alcanzado / implementación no autorizable todavía`, principalmente porque falta
una corrida INITIAL real, canónica y aceptada E2E.

Para abrir R1 después de este alto se requiere, en orden:

1. gate separado para aplicar/desplegar INITIAL con flags apagados;
2. un único canario INITIAL autorizado y su aceptación E2E;
3. resolver y versionar D1, D5, D6 y el alcance exacto de reevaluación;
4. comprobar transporte/proveedor sano;
5. aprobar `AGT002_INCREMENTAL_DESIGN_RECONCILED` y después, por separado,
   `AGT002_INCREMENTAL_IMPLEMENTATION_AUTHORIZED`.
