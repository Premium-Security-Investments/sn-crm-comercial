## Cierre productivo E1 — migración 055 (2026-07-31 UTC)

### Mismatch y corrección mínima

El canary controlado encontró `42501` cuando el loader backend intentó leer `public.psi_company_procurement_documents`. La migración 026 había revocado todos los privilegios, incluido el acceso del backend canónico.

La migración 055 normaliza las ACL y concede exclusivamente:

```sql
GRANT SELECT
ON TABLE public.psi_company_procurement_documents
TO service_role;
```

Después de aplicar 055 en producción:

- `service_select=true`;
- `INSERT/UPDATE/DELETE/TRUNCATE/REFERENCES/TRIGGER=false` para `service_role`;
- `public_select=false`;
- `anon_select=false`;
- `authenticated_select=false`;
- RLS permanece activa;
- marker 055 = `1/1`.

El runner incluye preflight, estados `absent/applied`, marker verificable, detección de privilegios backend inesperados, aplicación y rollback transaccionales, idempotencia y verificación terminal. El rollback revoca `SELECT` a `service_role` y exige cero privilegios para los cuatro roles con RLS activa.
